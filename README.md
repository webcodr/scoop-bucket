# webcodr scoop-bucket

A [Scoop](https://scoop.sh) bucket for [webcodr](https://github.com/webcodr) applications.

## Usage

```sh
scoop bucket add webcodr https://github.com/webcodr/scoop-bucket
scoop install jwtd
```

## Applications

- [jwtd](https://github.com/webcodr/jwtd) — Decode and pretty-print JSON Web Tokens with syntax highlighting

Manifests are published automatically by the jwtd release workflow.
